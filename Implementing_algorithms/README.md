# Implementing Algorithms (NLP)

هذا المجلد يحتوي على تنفيذ عملي (Implementation) لعدد من خوارزميات **معالجة اللغات الطبيعية (NLP)** باستخدام لغة **Python**، بهدف التعلّم والتجربة والفهم التطبيقي للخوارزميات الكلاسيكية والحديثة.

---

## 📌 محتويات المشروع

- تنفيذ خوارزميات NLP من الصفر أو باستخدام مكتبات معروفة
- معالجة النصوص العربية (Tokenization, Normalization, Stemming)
- استخراج السمات (Feature Extraction)
- تطبيق خوارزميات تصنيف وتحليل نصوص
- تجارب تعليمية مرتبطة بمادة **التنقيب عن البيانات / NLP**

---

## 🧠 الخوارزميات المنفذة (مثال)

> قد تختلف حسب الملفات الموجودة لديك

- Tokenization
- Bag of Words (BoW)
- TF-IDF
- N-grams
- Stemming (Khoja, Light Stemmer, …)
- Root Extraction
- Text Classification Algorithms
