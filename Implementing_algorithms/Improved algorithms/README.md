# Improved Algorithms (NLP)

هذا المجلد يحتوي على **نسخ محسّنة (Improved Versions)** من خوارزميات معالجة اللغات الطبيعية (NLP)، حيث تم تطويرها وتحسينها مقارنة بالتنفيذات الأساسية من حيث:

- الدقة
- الأداء
- تقليل التعقيد الزمني
- التعامل الأفضل مع النصوص العربية

---

## 📌 فكرة المجلد

بعد تنفيذ الخوارزميات الأساسية، تم العمل على:

- تحسين خطوات المعالجة المسبقة (Preprocessing)
- تحسين استخراج الجذور (Stemming / Root Extraction)
- تقليل الأخطاء الناتجة عن الضجيج اللغوي
- تحسين نتائج التصنيف والتحليل

هذا المجلد مخصص **للتجارب المتقدمة والتحسينات**.

---

## 🧠 الخوارزميات المحسّنة (مثال)

> قد تختلف حسب الملفات الموجودة

- Improved Tokenization
- Enhanced Normalization
- Improved Light Stemmer
- Optimized TF-IDF
- Enhanced Feature Selection
- Improved Text Classification Models
