# Arabic NLP Project – Preprocessing & Stemming

مشروع تعليمي وبحثي في **معالجة اللغة العربية (Arabic NLP)** يركّز على:
- المعالجة المسبقة للنصوص العربية
- خوارزميات Stemming
- تطبيق عملي بلغة Python
- تنظيم احترافي مناسب للمشاريع الجامعية وGitHub

---

## 📌 محتوى المشروع

- Normalization (توحيد الحروف وإزالة التشكيل)
- Tokenization (تقطيع النص)
- Stopwords Removal
- Light Stemmer
- Khoja Stemmer (نسخة تعليمية مبسطة)
- ملف تشغيل رئيسي `main.py`
